# 《Delta Force: Black Hawk Down》重力定位分析报告

- **目标文件**: `DFBHD_P.exe`（v1.5.0.5，32 位 PE，ImageBase `0x400000`，大小 2,547,712 字节）
- **分析方法**: 纯静态分析（python + capstone + pefile，字节级取证）
- **日期**: 2026-10-18
- **结论**: 引擎没有统一的重力常数。重力以 **16.16 定点立即数**硬编码在 **20 个独立的重力累加站点**中，分布在普通弹道 mover、10 余个 `useownmove` 抛掷物 mover、士兵 mover 和车辆 mover 内部。修改任意单一站点只会影响对应对象类型。

---

## 1. 地址换算约定

`.text` 节文件偏移与 VA 为 1:1 映射：`VA = 文件偏移 + 0x400000`。
本报告同时给出 VA 与文件偏移（`偏移 = VA − 0x400000`）。

## 2. 物理架构

### 2.1 mover 分发机制

抛射物/实体的逐帧移动由分发器决定：

```
0x491CB8  test ah, 0x80        ; 检查 useownmove 标志位
0x491CD3  call [obj+0x224]     ; 置位则调用实例自带的自定义 mover 函数
```

- 普通子弹走默认弹道函数 `0x491B00`。
- 手雷、炸药包、claymore 等在 items.def 中带 `useownmove` 关键字的弹药，走各自注册的 mover（`[obj+0x224]` 函数指针）。
- 士兵实体的 mover 由 `0x4168CD` 处的比较确认（`[obj+0x224] == 0x477310 / 0x477350 / 0x47CA90` 为士兵分支），其中 `0x477350` 是含重力的主 mover。

### 2.2 数值表示

- 物理量使用 **16.16 定点数**（证据：弹药记录默认值 `mov dword ptr [eax+0x1c], 0x10000` = 1.0）。
- 重力为**每帧累加到 Z 速度**的负值立即数：`vz += (-167)` 即每帧约 -0.002548 单位。
- Z 速度字段：子弹/士兵位于实例 `+0x74`，部分抛掷物 mover 使用 `+0x198` / `+0x19C`。
- 向下终端速度钳位：`cmp eax, 0xffffc000; jl → 钳到 -16384`（只钳向下，不钳向上）。

### 2.3 相关标志位（items.def 关键字）

| 关键字 | 存储位置 | 消费点 | 作用 |
|---|---|---|---|
| `nogravity` | def+0 位 `0x400` | `0x49286C test ah,4` → `jne` 跳过重力 | 该弹药不受重力 |
| `useownmove` | def+0 位 `0x8000`（高字节 0x80） | `0x491CB8 test ah,0x80` | 走自定义 mover |
| `nocollide` / `forcetracer` / `silenced` / `shrapnel` / `muzzle1/2` | def+0 其他位 | 弹道/音效/枪口代码 | 与重力无关，同表佐证关键字分组 |
| （阻力） | def+0x1C，16.16，默认 0x10000 | `0x491930`：`v = v*drag >> 16` | 速度衰减，水面以上叠加风矢量 `[0xE19DC0/4/8]` |

### 已排除的候选

- `0x473A04` / `0x473E94`（-83）：弹跳/末速处理，非重力。
- `0x439519`（-1336）：一次性冲量。
- `0x477525` / `0x47BA71`：动画/计时代码。
- 浮点常量 9.8 / 9.81 / 19.6 / 4.9 在 .text 中零命中（排除 float 写法）。

## 4. 关键反汇编证据

普通弹道 mover 的重力块（`0x49284C`–`0x492894`）：

```
0x49284C  mov  eax,[ebx+0x224]      ; 仅当 ==0 或 ==0x5382E0 才继续（默认 mover 门控）
0x492866  mov  eax,[ebx+0xd8]       ; 实例标志（= items.def def+0 的拷贝）
0x49286C  test ah,4                 ; nogravity 位 0x400
0x49286F  jne  0x492893             ; 置位 → 完全跳过重力
0x492871  test eax,0x100000         ; 入水标志
0x492878  cmp  ecx,[0xb63374]       ; 水面高度
0x492880  mov  eax,[ebx+0x74] / add eax,-0x14    ; 水下重力 -20
0x492888  mov  eax,[ebx+0x74] / add eax,-0xA7    ; 正常重力 -167
0x492890  mov  [ebx+0x74],eax
0x492894  call 0x491930             ; 紧随其后应用 drag
```

## 5. 补丁指南

### 5.1 实测过程（重要教训）

仅修改 A1（0x9288C）后实测：**只对普通子弹生效**，对 `useownmove` 手雷/炸药包/claymore 和人物无效——证实 mover 分发架构下每个 mover 自带重力常量。**修改重力必须全表批量处理**。

### 5.2 反重力（全部取反）

| 原字节序列 | 替换为 | 适用站点 |
|---|---|---|
| `59 FF FF FF` | `A7 00 00 00` | 所有 -167 |
| `B2 FE FF FF` | `4E 01 00 00` | 所有 -334 |
| `83 C0 EC` | `83 C0 14` | A2 水下 -20 |
| `83 Cx C9` | `83 Cx 37` | B6/B8/B11 水下 -55 |

注意：终端速度钳位（`0xFFFFC000`）只限制向下速度；反重力后向上速度无钳制，物体会持续加速升空直至飞出地图，属预期行为。如需限制上升，需同步把钳位改为正值分支。

### 5.3 减半 / 归零

| 目的 | 改法 |
|---|---|
| 减半 | -167→-83（`AD 00 00 00`）、-334→-167、-20→-10、-55→-27 |
| 归零（保留分支结构） | 立即数字节改 `00 00 00 00`；小立即数（`83 C0 EC` 类）改末字节为 `00` |
| 全局强制无重力（仅默认弹道） | `0x9286F` 处 `75 22`（jne）→ `EB 22`（jmp） |

### 5.4 风险提示

- 本报告所有偏移仅对应 **v1.5.0.5** 的 `DFBHD_P.exe`，其他版本需重新定位。
- 建议逐字节断言校验（先比对原字节再写入），本报告的补丁已按此方式生成并验证（20 站点 / 68 字节差异，全文件其余部分与原版逐字节一致）。
- 修改前务必备份原版；该 exe 无自校验迹象，异常时直接还原备份。

## 6. 与布娃娃（ragdoll）的关系

- 士兵下落与抛体共用"Z 速度定点累加 + 终端钳位"模式，但**骨骼矩阵完全由 .bad 关键帧驱动**，引擎无逐骨骼物理求解器（verlet/rigid/constraint 等关键词零命中）。
- 修改本表站点可改变尸体/人物的**根位置**运动（下坠、飘升、弹道），但无法让肢体产生物理摆动；真布娃娃仍需注入 DLL hook 骨骼写入路径并自建求解器。

# BHD 夜视仪（NVG）颜色实现分析

> 目标：DFBHD.exe（Delta Force: Black Hawk Down）
> MD5: `d6f51ad03ca62f040586b8b5e3ca8181` · Image Base: `0x400000` · 函数总数: 6777
> 工具：本地 Ghidra（反编译/交叉引用）+ pefile（字节级定位）
> 日期：2026-11-19
> 英文版：[NVG_Color_en.md](NVG_Color_en.md)

---

## 1. 结论速览

夜视仪的绿色**不是贴图，也不是灯光**，而是一段**内嵌在 exe 里的 ps.1.1 像素着色器源码文本**（ASCII 明文），游戏启动时由 D3DXAssembleShader 编译，渲染时作为全屏后处理 pass 应用：

```
场景像素 → 亮度提取(dp3 灰度化) → ×颜色增益 → +颜色底色 → 绿色画面
```

| 关键问题 | 答案 |
|---|---|
| 绿色定义在哪 | `0x64F8D4` 着色器源码文本中的 `def c1 / def c2` 两行 |
| 谁编译着色器 | `FUN_0052A9D0`（D3D 初始化时） |
| 谁应用绿色 | `FUN_0052BDB0`（步行）/ `FUN_0052C630`（车载） |
| 开关是谁 | `FUN_00489CC0` 输入动作处理器 `case 0x33`（N 键） |

## 2. 完整触发链

```
[键位表 .data 0x628488, 步长0x64]
  N键项 @0x629A04: id=0x33, key=0x4E, "!Night Vision", 命令 "NVG"
        │ 按键 N
        ▼
FUN_00489CC0 (输入动作处理器, switch(动作id))
  case 0x33:  DAT_0096C4BC = !DAT_0096C4BC      ← NVG 激活标志 0↔1
              FUN_004BE3A0(DAT_00A02028/2C)     ← 开/关音效
        │
        ▼
FUN_004B7110 (主渲染函数)
  if (DAT_0096C4BC != 0) → 特殊视野分支
        │
        ▼
FUN_0052BDB0 (步行NVG渲染) / FUN_0052C630 (车载NVG渲染)
  有像素着色器: 绑定 DAT_00E049B0 (NVG着色器) 画全屏quad
  无像素着色器: 固定管线绿色顶点色调制（兜底）
```

键位表项结构（0x64 字节/项）：`{id: dword, flags: 5字节, param: dword, key: dword, "!显示名": char[28], "命令名": char[45]}`。该表无任何代码直接引用（纯默认数据），动作经 `id` 字段分发。

## 3. 核心地址一览（重点）

### 3.1 颜色本体 —— 着色器源码文本 @ `0x64F8D4`

```asm
ps.1.1
def c0, 0.50,  1.00,  0.50,  0.0   ; 亮度权重 (R,G,B) —— 灰度化用，非颜色
def c1, 0.20,  0.90,  0.20,  0.0   ; ★ 颜色增益 —— "绿色"的主来源（G=0.90）
def c2, 0.00,  0.20,  0.00,  0.0   ; ★ 颜色底色 —— 暗部保留 0.2 绿色

tex t0                             ; 取场景纹理
dp3     r0, t0, c0                 ; 点积 = 亮度提取 → 灰度图
mul  r0, r0, c1                     ; 乘颜色增益
add     r0, r0, c2                 ; 加底色 → 全画面绿染
```

数值含义：`c1` 决定"什么颜色最亮"，`c2` 决定"黑处泛什么色"。原版 G 通道增益 0.90 + 底色 0.20，R/B 仅 0.20/0.00 —— 典型夜视绿。

### 3.2 颜色常量（固定管线兜底路径）

不支持像素着色器的显卡走固定管线，用**顶点色调制**近似同一效果：

| 地址 (VA) | 原始值 | 含义 |
|---|---|---|
| `0x52BE16` | `0xFF408040` | 步行 NVG · PS 路径顶点色（ARGB，A=FF 不透明） |
| `0x52C7EA` | `0xFF408040` | 车载 NVG · PS 路径顶点色 |
| `0x52BE77` | `0xFF084808` | 步行 · 固定管线暗部 |
| `0x52C854` | `0xFF084808` | 车载 · 固定管线暗部 |
| `0x52BEBB` | `0xFF308030` | 步行 · 固定管线标准亮度 |
| `0x52BEB3` | `0xFF30FF30` | 步行 · 固定管线增亮档（NVG 增亮开） |

> 格式说明：D3DCOLOR 按 `AARRGGBB` 排列。开头的 `FF` 是 Alpha=255（完全不透明），真正的 RGB 是后 6 位。例：`0xFF30FF30` = R:0x30, G:0xFF, B:0x30。

### 3.3 功能函数地址

| 地址 | 函数 | 作用 |
|---|---|---|
| `0x52A9D0` | `FUN_0052A9D0` | 特殊视野初始化：编译 4 段 ps.1.1 着色器、加载 `Binoculr.tga` 目镜 HUD 贴图 |
| `0x52BDB0` | `FUN_0052BDB0` | **步行 NVG 渲染**：全屏绿色 pass |
| `0x52C630` | `FUN_0052C630` | 车载 NVG 渲染（同一着色器句柄） |
| `0x4B7110` | `FUN_004B7110` | 主渲染分发：按 `DAT_0096C4BC` 走特殊视野分支 |
| `0x489CC0` | `FUN_00489CC0` | 输入动作处理器：`case 0x33` = N 键开关 NVG |
| `0x629A04` | 键位表数据 | N 键绑定项（id 0x33 → "!Night Vision" → 命令 "NVG"） |

### 3.4 关键全局变量

| 地址 | 含义 |
|---|---|
| `DAT_0096C4BC` | NVG 激活标志（1=开）。有效写入点仅 `FUN_00489CC0` case 0x33，其余全是清零 |
| `DAT_0096C4B0/B1` | 望远镜模式（B 键，id 0x23；每帧 `FUN_004240C0` 中 B0=B1） |
| `DAT_00E049B0` | NVG 着色器句柄（PS 路径）；无 PS 时改存固定管线 stage-state 配置 |
| `DAT_00E049CC` | 增亮标志（=1 时兜底路径用 `0xFF30FF30` 亮绿） |
| `DAT_00E049C0/C4` | `Binoculr.tga` 目镜 HUD 贴图句柄 |

## 4. 着色器初始化（`FUN_0052A9D0`）细节

D3D 设备创建后一次性执行，共编译 **4 段 ps.1.1 着色器**（`FUN_0057BC42` = D3DXAssembleShader）：

| 源码 VA | c0 (亮度权重) | 用途 | 存放 |
|---|---|---|---|
| `0x64F8D4` | 0.50, 1.00, 0.50 | **NVG 绿染**（本文主角） | `DAT_00E049B0` |
| `0x64F99C` | 0.50, 0.50, 0.50 | 中性灰度（望远镜系） | `DAT_00E04998` |
| `0x64F728` | 0.30, 0.60, 0.10 | 4 纹理组合版 | `DAT_00E049B4` |
| `0x64FAA4` | 0.30, 0.60, 0.10 | 单纹理版 | `DAT_00E049A8` |

若设备不支持 PS 或 D3D 等级不足，`DAT_00E049B0` 改由 `FUN_005AB760` 填充固定管线纹理阶段配置，`DAT_00E049CC=1` 启用增亮。

## 5. 换色补丁方案

脚本：`nvg_color_patch.py`（与仓库内报告配套分发）

```bash
python nvg_color_patch.py FF5533 DFBHD.exe      # 橙红夜视仪
python nvg_color_patch.py 00C8FF "C:\\Games\\BHD\\DFBHD.exe"   # 青蓝夜视仪
```

源 exe 路径作为第 2 个参数传入（省略时依次尝试：当前目录 → 脚本目录下的 `DFBHD.exe`）。脚本只读源文件。

原理（**全部等长原地替换**，不动任何偏移/结构）：

1. **着色器源码**（0x64F8D4）：只重写 `def c1/def c2` 两行数字文本
   - 映射：`c1 = RGB × 0.9`（增益）、`c2 = RGB × 0.2`（底色），动态范围与原版一致，仅换色调
2. **兜底颜色**（6 处 imm32）：按原亮度等级（0.50 / 0.28 / 1.00）整体缩放为自定义 RGB，Alpha 恒为 FF
3. 安全性：不依赖 md5，直接**逐字节校验补丁点**（颜色常量原值比对 + 着色器格式正则匹配），任何不符立即拒绝补丁
4. 输出**新文件** `DFBHD_NVG_<色值>.exe`，不触碰游戏目录，自行复制使用

## 6. 分析方法备忘

- Ghidra 对 `0x62xxxx` 键位数据块无交叉引用 → 改用 **pefile 全文件 imm32 扫描**定位代码引用；需排除 `E8/E9/0F8x`（call/jcc 位移）误报
- 着色器源码按 `"ps.1.1"` 关键字过滤字符串是定位渲染效果的最快入口
- `0x64A6F8` 的 `NVG_FLIP` 是角色模型动画标记（翻镜动作），非效果本体；`ITEMS_.DEF` 中 "Night Vision Goggles"（id 101904, graphic nvg）是世界拾取模型，亦非效果本体
